### 任务背景

确认 `scripts/lade_llm_context_queries_single.py` 如何选择查询，尤其是仅使用 i0 的方法。

### 关键结论

- 使用 `--queries i0` 即可只选择 i0，无需修改脚本。
- 不传 `--queries` 时默认选择 core，包含 i0、i1、i3、i4、i5、i6、i9。
- 多条查询使用逗号，例如 `--queries i0,i3,i5`；连续范围使用 `--queries i0-i3`；也支持查询包和类别。选择结果按首次出现顺序去重。
- i0 查询指定 run_id 和 drone_id 的 Drone 当前属性，不需要 step_index 或 time_minute。
- 查询种类和执行次数分别控制：多个 drone 或 `--repeat` 大于 1 时，i0 会执行多次。
- 已用 `--dry-run` 验证输出仅包含 i0，未连接 Neo4j 或执行实际数据库查询。

### 执行过的操作

- 使用 rg、sed 阅读目标脚本的查询定义、QUERY_PACKS、select_queries、参数解析及执行入口。
- 阅读 `run_in_lade.sh`，确认通过 lade 环境运行。
- 执行预览：

```bash
./run_in_lade.sh python scripts/lade_llm_context_queries_single.py \
  --queries i0 --run-id EXAMPLE_RUN_ID --drone-id drone-1 --dry-run
```
