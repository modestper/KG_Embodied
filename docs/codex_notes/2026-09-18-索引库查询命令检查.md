### 任务背景

用户希望检查通过 `47687` 端口对 `lade-query-neo4j-index` 执行 100 drone、20 次 repeat、全部即时查询的命令是否正确。

### 关键结论

- Shell 语法和 `DRONE_IDS` 生成方式基本正确。
- `47687` 确实是规划中的索引版 Bolt 端口，但此前索引版容器尚未创建成功，必须先确认容器存在且端口可连接。
- 密码只有在索引版由 `lade-query-neo4j-data` 克隆成功后才与无索引查询库相同；不应仅凭命令假设密码正确。
- `--queries all` 包含 i2；当前 i2 使用 Neo4j 不支持的 `BETWEEN` 写法，预计会产生失败记录。暂时应使用 `--queries i0,i1,i3-i11`，或先修复 i2。
- JSONL 使用追加模式。重复执行相同文件名会混合多轮结果，正式实验应使用本轮独立文件名。
- 100 drone × 20 repeat × 11 个有效模板会尝试 22000 条查询；使用 all 则为 24000 次尝试，其中 i2 预计失败 2000 次。

### 后续建议

先确认容器：

```bash
sudo docker ps --filter name=lade-query-neo4j-index
```

确认索引：

```bash
sudo docker exec -it lade-query-neo4j-index cypher-shell \
  -u neo4j -d neo4j \
  "SHOW INDEXES YIELD name,state WHERE name STARTS WITH 'lade_agent_state_' RETURN name,state ORDER BY name;"
```

三条索引均为 ONLINE 后再运行查询。推荐命令：

```bash
read -rsp '索引库密码: ' INDEX_NEO4J_PASSWORD
echo
export INDEX_NEO4J_PASSWORD

DRONE_IDS=$(printf "drone-%s," $(seq 1 100))
DRONE_IDS=${DRONE_IDS%,}

NEO4J_URI=bolt://127.0.0.1:47687 \
NEO4J_USER=neo4j \
NEO4J_PASSWORD="$INDEX_NEO4J_PASSWORD" \
NEO4J_DATABASE=neo4j \
./run_in_lade.sh python scripts/lade_llm_context_queries.py \
  --run-id million-nodes-hangzhou-0621-100agents \
  --drone-ids "$DRONE_IDS" \
  --step-index 2300 \
  --queries i0,i1,i3-i11 \
  --repeat 20 \
  --max-workers 100 \
  --max-connection-pool-size 100 \
  --query-log-jsonl data/index_20260918_query_logs.jsonl \
  --context-jsonl data/index_20260918_contexts.jsonl \
  --summary-json data/index_20260918_summary.json

unset INDEX_NEO4J_PASSWORD
```

做有/无索引 A/B 时，无索引版只修改 URI 为 `37687`，并使用不同日志文件名；其他参数必须完全相同。
