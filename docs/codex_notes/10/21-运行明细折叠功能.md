# 运行明细折叠功能

日期：2026-10-21

### 任务背景

用户希望给前端“运行明细”增加折叠功能。本轮为实时仿真页该区域增加展开/收起按钮，默认保持展开。

### 关键结论

- “运行明细”标题旁新增“收起/展开”按钮，图标与提示同步切换。
- 收起时隐藏无人机/任务切换标签和明细内容，保留区域标题及展开入口。
- 折叠不暂停或重启仿真，后台帧继续接收，顶部指标和 Step 继续更新。
- 重新展开保留原来的标签、筛选条件、搜索内容和分页位置。
- “最近事件”是独立面板，保持显示；刷新页面后默认展开。
- 鼠标、Enter/Space 键盘操作及桌面、手机布局验证通过，未访问现有仿真或数据库。

### 执行过的操作

- 阅读 `dynamic.html` 的运行明细结构、`src/dynamic_app.mjs` 的事件与渲染逻辑，以及相关公共样式。
- 增加折叠按钮、内容容器、可访问性属性及对应样式，更新前端资源版本标识。
- 运行 `node --check src/dynamic_app.mjs` 和 `git diff --check`。
- 使用临时 Playwright/Chromium 隔离验证：默认展开、点击收起、区域高度缩减、事件面板保留、折叠时继续收帧、无重连、重新展开保留筛选分页、Enter/Space 操作，以及 1440/1024/390px 无页面横向溢出。

浏览器未出现页面脚本错误，真实 `/events` 请求数为 0。测试使用临时随机端口及示例帧，不操作现有服务。
