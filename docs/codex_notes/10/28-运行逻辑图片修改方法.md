可视化编辑方法：

1. 将 SVG 文件下载到自己的电脑，用 Inkscape 打开。浏览器打开通常只是预览；图形编辑器才用于选中、移动和修改对象。
2. 选择文字工具 `T` 或 `F8`，点击现有文字进行修改；文字工具使用方法见[入门手册](https://inkscape-manuals.readthedocs.io/en/latest/writing-text.html)。
3. 用选择工具选择矩形、文字或箭头，调整位置、大小或颜色。若要把一个模块整体移动，同时选择它的底框与文字，按 `Ctrl+G` 编组，再移动；见[编组说明](https://inkscape-manuals.readthedocs.io/en/latest/grouping.html)。当前图没有自动绑定的流程图连接线，移动框后需要检查箭头端点。
4. 保存 SVG，保留其文字与形状的可编辑性。
5. 按 `Ctrl+Shift+E` 打开 PNG 导出，选择页面范围，设置宽度 `1800` 像素可保持现有导出尺寸，再选择文件名导出；见[PNG 导出说明](https://inkscape-manuals.readthedocs.io/en/latest/export-png.html)。建议先另存副本，确认布局后再使用新图。

这份 SVG 指定了 `Noto Sans CJK SC`、`Microsoft YaHei` 等字体。在另一台电脑上编辑时，如果缺少这些字体，替代字体可能改变文字宽度；导出前检查文字是否溢出。

源码编辑方法：

用 VS Code 等文本编辑器打开 SVG。图中主进程标题为：

```xml
<text x="85" y="344" class="heading">主进程</text>
```

- 改名称：修改标签里的“主进程”。
- 改位置：修改 `x`、`y`，其中 y 是文字基线的位置。
- 改字体大小：修改顶部 `.heading`、`.body` 等样式，或为单个对象设置样式。
- 改框的位置和大小：修改对应 `<rect>` 的 `x`、`y`、`width`、`height`。
- 改背景/边框颜色：修改 `fill`、`stroke`。
- 改箭头路线：修改对应 `<path>` 的 `d`。例如 `M500 390 H700` 表示从 `(500,390)` 水平画到 x=700；移动模块时要同时调整箭头和旁边的标签文字。

修改并保存后，浏览器重新打开或刷新 SVG 即可预览。文字较长时需要调整字号、宽度或拆成多行，当前源码没有自动排版功能。

服务器上重新生成 PNG 的现有命令：

```bash
node /tmp/lade_runtime_diagram_simple_20261028.cjs
```

这条命令读取原路径下的 SVG，并覆盖同目录的同名 PNG。脚本会等待字体就绪并检查文字是否超出画布；它不检查模块之间是否重叠，也不会自动修复布局。本次只检查了脚本和依赖文件存在，没有执行此覆盖操作。

如修改画布尺寸，还需要同步调整脚本中的 `viewport` 和 `1200/880` 边界检查；只改现有画布内的文字、布局和配色通常无需改导出脚本。

### 后续建议

1. 日常修改使用 SVG 作为源文件，再导出 PNG 用于汇报、文档或分享。
2. 若主要是拖动模块和调整文字，使用可视化编辑器；若只是替换几句话，用代码编辑器搜索原文修改更直接。

4. `/tmp` 依赖可能被清理。长期复用时可把导出流程整理成项目脚本，或直接使用本地编辑器导出。
