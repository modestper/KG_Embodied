# 前端页面美化实施

日期：2026-10-21

### 任务背景

用户确认采用此前的前端美化方案，希望直接查看修改后的页面效果。本次以实时仿真页为重点，统一三页的浅色监控台风格，整理页面层级，并完成与新界面相关的公共代码整理和交互优化。

前置分析见：[前端展示代码分析与美化方案](./21-前端展示代码分析与美化方案.md)。

### 关键结论

- 三个页面已统一导航、品牌、浅色背景、面板、按钮、指标与状态样式；实时页优先突出地图，适配桌面和手机。
- 实时页侧栏默认展示常用场景参数，运行/推送、Ray 和 LLM 配置分组折叠；合并重复的重新运行与重置视图入口。
- 播放、历史回放速度、时间轴与地图控制集中在地图附近；任务与 Agent 状态置于地图下方，查询与 LLM 原始内容按需展开。
- 任务支持搜索、状态筛选及每页 50 条分页；Agent 增加中文状态徽标、电量条，保留求助与支援标识。
- 抽出公共 Canvas 与界面工具；地图拖拽、缩放、边界调整不再连带重建表格，Canvas 尺寸只在实际变化时更新。
- 修正配送中任务与待派单任务同色的问题；静态页场景标题来自所选 trace，并增加进度拖动、文件大小、加载与失败反馈。概览小时图明确标注全局统计口径。
- 6 个前端测试文件通过；隔离浏览器完成 11 组交互验收，无页面脚本错误。没有访问现有 `/events`，没有查询真实数据库，没有重启仿真服务。

#### 主要交互变化

| 操作 | 当前行为 |
| --- | --- |
| 修改场景 | 侧栏修改城市、日期、无人机数量、任务数量，点击“应用参数并重新运行”生效 |
| 高级配置 | 展开“运行与推送”“执行后端”“智能调度”；LLM 未启用时隐藏模型字段，显式选择 Local 时隐藏 Ray 字段 |
| 暂停画面 | 保持后端继续运行，可以回看已接收的帧，点击“实时”恢复跟随 |
| 首次互助 | 保留自动暂停画面的演示行为，并明确显示暂停原因 |
| 查看明细 | 在“无人机状态 / 任务列表”间切换，支持方向键、Home、End 键 |
| 任务查询 | 支持按未完成、已完成、互助任务筛选，以及按任务、无人机、区域搜索；分页不删除任务 |
| 图谱查询 | 顶部入口可直接展开查询工作区；仍仅在手动提交时执行，保留五项耗时、历史、提示及 JSON 导出 |
| 静态回放 | 可拖动回放进度，播放、暂停、从头回放；文件切换时停止旧回放并取消旧请求，失败后可换文件恢复 |

### 执行过的操作

读取并修改三个 HTML 入口、公共样式和主要页面脚本；核对服务端事件接口与快照结构，仅用于保证前端兼容，没有修改后端。

关键验证命令：

```bash
node --test tests/*.test.mjs
node --check src/dynamic_app.mjs
node --check src/simulation_app.mjs
node --check src/app.mjs
git diff --check
```

浏览器验证使用临时安装在 `/tmp/lade-viewer-ui-check` 的 Playwright、Chromium，测试脚本为 `/tmp/lade_viewer_ui_smoke_20261021.mjs`。没有新增项目运行依赖，临时 HTTP 服务绑定随机端口并在验收后关闭。

浏览器验收覆盖：

1. 实时帧接收、指标、Agent 状态和工具默认折叠。
2. 通过 DOM 变更观察确认缩放、拖拽地图不重建 Agent 表。
3. 任务搜索、筛选及分页。
4. 明细标签的键盘切换。
5. 历史回看期间继续接收帧、回到实时、首次互助自动暂停及角色标识。
6. 查询面板展开不执行查询，手动执行后展示五项耗时并导出结果。
7. Ray/LLM 配置展开与隐藏，重新运行保留参数，推送间隔支持 0。
8. 1920、1440、1280、1024、768、390px 窗口的页面横向溢出检查，以及手机参数默认收起。
9. 本地小型 trace 的标题、加载、拖动进度、播放与从头回放。
10. 轨迹文件加载失败时保留页面，切换有效文件后恢复。
11. 本地概览数据加载、城市和任务类型筛选、24 小时图及窄屏布局。

另外检查了三页无重复 DOM ID，格式化了修改的 HTML、CSS、模块和新增测试。Python 操作均通过 `./run_in_lade.sh python` 执行。

### 修改内容

| 文件 | 修改目的 |
| --- | --- |
| `dynamic.html` | 重组实时页侧栏、导航、地图控制、指标、明细标签、筛选分页及折叠工具 |
| `simulation.html` | 统一回放页外观，新增场景动态标题、加载反馈和回放进度条 |
| `index.html` | 统一概览页外观，补充指标说明和小时图统计口径 |
| `src/styles.css` | 统一浅色视觉、控件状态、面板、表格、徽标、图例与响应式布局 |
| `src/dynamic_app.mjs` | 适配新控件，保留时间轴行为，实现分页筛选、状态呈现和地图独立重绘 |
| `src/simulation_app.mjs` | 适配回放进度、动态标题、文件加载和失败恢复，复用地图工具 |
| `src/app.mjs` | 复用 Canvas 工具，增加小时高峰说明与柱形辅助标签，保留页面框架显示错误 |
| `src/canvas_utils.mjs` | 公共 Canvas 尺寸、投影、网格、拖拽缩放、状态颜色与历史状态解析 |
| `src/ui.mjs` | 公共状态徽标、文本转义、折叠入口、键盘标签切换及错误提示 |
| `tests/canvas_utils.test.mjs` | 验证历史与最终状态区别、未下发任务、窄屏投影、设备像素比和 Canvas 尺寸复用 |
| 本文及配套预览、验收结果 | 保存实施说明与可查看的效果 |

未改动后端、实验数据、运行参数默认值或数据库配置；没有提交或推送 Git。工作区同时出现的 Ray 说明文档未做改动。

### 后续建议

- 可以先查看桌面、手机预览，再在现有服务上查看实际页面。静态文件修改不需要重启服务；浏览器强制刷新可以避免旧资源缓存。实时页刷新仍会按原有逻辑重新连接并启动仿真，正在跑重要实验时可先看预览。
- 本轮无待确认或阻塞事项。后续可根据实际观感继续调整主色、字号、地图高度及默认明细标签。
- 大型 trace 分块读取、长期历史缓存、逐城小时统计属于后续专项。本轮保留完整历史和现有数据格式，小时统计仍使用全局数据并明确标注。
