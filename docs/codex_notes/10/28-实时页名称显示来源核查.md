### 关键结论

- 实时页的品牌、副标题、顶部导航文字和页脚名称都直接写在 `dynamic.html`，不是后端仿真数据生成的。
- 当前源码中的两类完整旧名称均已替换；`src/dynamic_app.mjs` 中没有将它们覆盖回旧值的逻辑。
- 已用普通 HTTP 客户端请求 `http://127.0.0.1:8010/dynamic.html`，返回 200，响应内容与当前磁盘文件逐字节一致，完整旧名称出现次数均为 0。
- 已打开的实时页面不会因为磁盘 HTML 改名就自动替换现有 DOM；实时流更新仿真数据，没有重新加载品牌文案。浏览器仍显示完整旧名称时，优先排查未重新加载的页面和缓存，当前未直接检查用户浏览器，不能断言具体是哪一种。
- 源码仍保留左下角“多智能体协同配送”和三页 Logo 旁的 `LAB`；如果希望名称全面统一，可分别继续调整。
- 不需要为这些静态文案重启后端。实时页刷新会按现有逻辑连接 `/events` 并发起运行，正在跑重要实验时可等实验结束后刷新，或仅临时更新当前页面 DOM。
