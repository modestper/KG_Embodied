### 任务背景

用户希望统计 `/data/zc/datasets/LaDe` 数据集中哪些城市-日期的 delivery task 数达到 `10000` 左右，并计算当天第一个包裹到最后一个包裹的时间跨度。

### 关键结论

- 本次默认将 `10000 左右` 定义为 `9000-11000` 条任务。
- 统计基于 `/data/zc/datasets/LaDe/delivery/` 下五个城市原始 CSV，不使用 `delivery_five_cities.csv`，因为后者不是五城完整合并。
- 共筛出 `119` 个城市-日期组合。
- 按城市分布：`Chongqing=9`、`Hangzhou=46`、`Shanghai=64`、`Jilin=0`、`Yantai=0`。
- 完整结果已保存到 `data/lade_daily_around_10000_task_stats.csv`。
- 结果同时保留两种跨度：
  - `same_day_accept_span_*`：`accept_time` 日期与 `ds` 一致的当天接单窗口，推荐作为“当天第一个包裹到最后一个包裹”的口径。
  - `same_day_first_accept_to_last_delivery_*`：当天最早接单到最晚送达，可能包含跨天/长尾配送。
- 发现 1 个筛选结果存在 `accept_time` 与 `ds` 不一致的记录：`Chongqing 1018` 有 1 条 mismatch。

### 执行过的操作

- 查找 delivery CSV：`find /data/zc/datasets/LaDe -maxdepth 3 -type f -name 'delivery*.csv'`
- 查看字段：`head -n 2 /data/zc/datasets/LaDe/delivery/delivery_jl.csv`
- 统计文件行数：`wc -l /data/zc/datasets/LaDe/delivery/delivery_*.csv /data/zc/datasets/LaDe/delivery_five_cities.csv`
- 用 Python 流式读取五个城市 CSV，按 `city + ds` 聚合：
  - `task_count`
  - `same_day_first_accept`
  - `same_day_last_accept`
  - `same_day_accept_span_hhmmss`
  - `first_delivery`
  - `last_delivery`
  - `same_day_first_accept_to_last_delivery_hhmmss`
  - `accept_date_mismatch_count`
- 检查结果行数：`wc -l data/lade_daily_around_10000_task_stats.csv`
- 查看结果前几行：`sed -n '1,20p' data/lade_daily_around_10000_task_stats.csv`
- 统计城市分布和最接近 10000 的日期。
