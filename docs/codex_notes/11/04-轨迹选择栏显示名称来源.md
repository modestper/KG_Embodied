# 轨迹选择栏显示名称来源

### 任务背景

用户确认轨迹回放文件选择栏是否自动将名称显示为城市、任务数和 agent 数量。本轮只读核查显示标签与实际文件路径的对应逻辑。

### 关键结论

- 下拉框使用索引条目的 `label` 显示名称，使用 `file` 保存真实文件路径，不会修改磁盘文件名。
- 标签格式为“城市 日期 · 任务数 tasks · 无人机数 agents”，数据分别来自轨迹内部的 `config.city`、`config.day`、`metrics.total_tasks`、`metrics.drones`，不是解析原始文件名。
- 手动保存轨迹接口会自动生成标签并更新索引；仅手动复制文件到目录不会触发前端扫描，需要另行更新索引。
- 相同配置的不同文件可能具有相同显示标签，索引仍通过不同的 `file` 区分它们。

### 执行过的操作

- 阅读 `scripts/build_trace_index.py` 的 `trace_entry()`。
- 阅读 `src/simulation_app.mjs` 的 `loadTraceIndex()`。
- 核对 `scripts/trace_storage.py` 保存后的索引更新调用。
- 阅读当前 `data/traces.json` 的真实 `file` 与 `label` 对应示例。

### 修改内容

仅新增本文档，没有修改回放界面、轨迹文件或索引。

当前索引示例：实际文件 `traces/上海市_20261104_154722.json`，显示标签为 `上海市 0621 · 5 tasks · 3 agents`。标签中的日期是模拟配置日期，不是文件名中的保存日期。

### 后续建议

- 若需区分同配置下的多次运行，可以另行在显示标签中加入文件名或保存时间；本轮未实施该修改。
