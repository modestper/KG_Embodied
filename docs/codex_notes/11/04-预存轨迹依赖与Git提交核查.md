# 预存轨迹依赖与 Git 提交核查

### 任务背景

用户担心保存的轨迹文件较大，上传 GitHub 增加仓库体积，并希望确认现有代码是否依赖这些文件、缺少轨迹是否报错。本轮只读检查代码、索引和 Git 跟踪状态，没有删除文件或修改运行逻辑。

### 关键结论

- 实时模拟从原始配送 CSV 和运行参数创建环境，通过 SSE 发送新快照，不依赖历史轨迹 JSON。导入 `build_delivery_sim.py` 是复用常量等代码，并不等于读取其输出的轨迹文件。
- 数据概览依赖 `data/summary.json`，另读取区域边界作为地图辅助数据，不依赖轨迹列表。不能为忽略轨迹而一并忽略整个 `data/`。
- 轨迹回放依赖 `data/traces.json` 及当前选中的轨迹。并不是所有轨迹都必须在本地，但选中缺失文件时会出现 HTTP 404 和“轨迹加载失败”。现有切换事件已绑定，可以切换到其他有效轨迹。
- 索引文件缺失时，回放初始化直接失败，显示错误提示；索引为空时，代码还会回退读取 `delivery_sim_current.json`。如果没有默认文件，仍然报加载错误，尚无完善的“暂无轨迹”空状态。
- 索引当前列出 9 个文件，本机均存在，但只有 `traces/上海市_20261028_170855_aee32deb.json` 被 Git 跟踪，其大小约 10 MiB。当前首项 `traces/上海市_20261104_154722.json` 尚未跟踪。
- `.gitignore` 已忽略 `data/delivery_sim*.json`，尚未忽略新的 `data/traces/` 保存目录，因此后续运行产物仍可能被加入 Git。
- 只向仓库提交索引、却不提交其中对应的轨迹，其他机器克隆后可能看到无法加载的下拉选项。当前已提交索引的第一项对应已跟踪轨迹，因此不能把当前 HEAD 描述为默认回放必然失败；但其其他未跟踪条目仍可能失效。
- 本轮没有更改 `.gitignore`、索引或 Git 跟踪状态，也没有删除本地轨迹。

### 执行过的操作

- 使用 `git status --short`、`git ls-files data` 核对工作区及已跟踪文件。
- 阅读 `.gitignore`，使用 `du -h` 查看本地轨迹体积。旧轨迹中有约 329 MiB 和 251 MiB 的文件，这些当前未被 Git 跟踪。
- 阅读 `src/simulation_app.mjs` 的索引读取、默认轨迹选择、错误提示及切换恢复逻辑。
- 阅读 `src/app.mjs` 的数据概览依赖，以及 `scripts/run_dynamic_sim.py` 的新模拟创建流程。
- 核对 `scripts/build_trace_index.py` 的索引重建方式。
- 通过 `./run_in_lade.sh python -c ...` 对比索引条目的本地存在状态、Git 跟踪状态和 HEAD 索引首项。
- 未访问现有模拟的 `/events`、执行数据库查询或重启服务。本轮为代码分析，未运行功能测试。

### 修改内容

仅新增本核查文档。

缺失文件的行为汇总：

| 场景 | 当前行为 |
| --- | --- |
| 不存在某个未选中的轨迹 | 不会主动加载它，不影响当前有效轨迹播放 |
| 选中或通过 URL 指定不存在的轨迹 | 显示加载失败，可选择其他存在的轨迹 |
| 默认选中的首项缺失 | 首次进入回放页出现错误，不会自动跳过失效首项 |
| `traces.json` 缺失或不合法 | 回放初始化失败 |
| 索引为空且默认文件也不存在 | 仍尝试默认文件并显示错误，尚未优雅展示空状态 |
| 所有历史轨迹都不随仓库分发 | 实时模拟、查询和数据概览没有因此新增依赖；回放需要生成或保存新的轨迹，并处理索引与空状态 |

### 后续建议

建议将轨迹明确视为运行产物，后续采用以下配套改动：

1. 忽略 `data/traces/` 下的运行产物；如果决定取消跟踪已经提交的轨迹，应保留服务器本地文件。仅追加 `.gitignore` 不会让已跟踪文件自动停止跟踪，也不会清除 Git 历史中的文件。
2. 为回放增加缺失索引、空列表、失效文件的友好处理，空列表不再强制加载默认文件；索引失效时提示重新生成或保存轨迹。
3. 决定仓库是否保留一个体积很小的演示轨迹。若保留，应让演示索引只引用随仓库分发的文件；本地运行索引可在部署后生成。
4. 对实际服务器，保存新轨迹会继续自动更新列表；人工删除或迁移文件时，应同步更新索引。现有 `build_trace_index.py` 只索引当前存在且结构可识别的 JSON，但会解析完整文件，重建大量大型轨迹时有额外开销。

以上为建议，本轮未实施删除、取消跟踪、索引重写或功能改动。
