### 任务背景

用户希望在动态仿真前端页面中，为区域边界图增加紧凑的显示设置控件。控件需要支持显示/关闭边界、调整边界线粗细、调整颜色深浅，并尽量减少对页面空间的占用。

### 关键结论

- 已在动态页面 `dynamic.html` 的地图标题工具栏中新增折叠式“边界”控件。
- 默认状态只显示一个小的“边界”入口，不额外占用主页面空间。
- 点击“边界”后会展开浮层设置项。
- 设置项包括显示开关、线宽滑块、深浅/透明度滑块和颜色选择器。
- 设置变更会立即触发 canvas 重绘，不需要重启仿真。
- 本次只修改动态仿真页面；静态回放页面当前没有同样的 region boundary 数据注入，因此未同步增加控件。

### 执行过的操作

- 读取 `dynamic.html`，定位实时派送轨迹地图面板。
- 读取 `src/dynamic_app.mjs`，定位 `state.regions`、`renderCanvas()` 和 `drawRegionOutlines()`。
- 读取 `src/styles.css`，定位地图面板和工具栏样式。
- 新增动态页面控件结构测试。
- 修改动态页面 HTML、前端绘制逻辑和紧凑浮层样式。
- 运行相关测试和语法检查。
- 尝试启动动态服务做页面检查；沙箱内直接绑定端口失败后，使用批准的非沙箱方式启动，服务成功打印访问地址，随后已手动终止检查进程。

### 修改内容

- `dynamic.html`
  - 在实时派送轨迹面板工具栏中新增 `regionBoundaryMenu` 折叠菜单。
  - 新增 `regionBoundaryEnabled`、`regionBoundaryWidth`、`regionBoundaryOpacity`、`regionBoundaryColor` 控件。

- `src/dynamic_app.mjs`
  - 新增 `state.regionBoundary` 保存边界显示状态、线宽、透明度和颜色。
  - 新增边界控件事件监听。
  - 新增 `updateRegionBoundaryStyle()` 和 `normalizedFloat()`。
  - 修改 `drawRegionOutlines()`，按用户设置绘制或隐藏边界。

- `src/styles.css`
  - 新增 `.compact-menu`、`.compact-menu-panel`、`.mini-control` 等紧凑控件样式。
  - 控件展开后以小浮层呈现，避免撑大地图标题栏。

- `tests/dynamic_server_test.py`
  - 新增测试，确认动态页面暴露边界控件所需 DOM。

### 后续建议

- 打开动态页面后，在“实时派送轨迹”标题右侧点击“边界”即可展开设置。
- 如果后续希望静态回放页面也支持边界控制，需要先把 region boundary 数据写入 trace 或在静态页面额外加载 `data/region_boundaries.json`。
- 如果希望保存用户偏好，可以进一步把边界设置写入 `localStorage`。
